# v0.1.0 源码预览草案

本页不是发布公告，不创建 tag、GitHub Release 或上传 artifact。

## 定位

RoomSentry 是本地优先的家庭事件分析研究原型，提供媒体/信号适配器、有界证据、结构化结果、SQLite、队列与本地回看。功能开发已暂停，公开源码用于保存通用实现。

宝宝独立检测、遮挡、连续追踪、语义事件与长期运行仍未验收；不提供看护安全保证。

## 源码范围

包含项目自有代码、合成测试、Schema、通用配置和部署模板。不包含家庭媒体、私人标注、逐帧预测、设备清单、账号数据、运行数据库、模型权重或厂商私有运行树。

第三方组件按 [许可证边界](../../THIRD_PARTY_LICENSES.md) 独立处理。上传、通知、生物特征、删除与自动启动默认关闭。

## 发布前检查

```bash
bash scripts/verify_source_release.sh
```

该脚本只在本地验证 Git index、源码包与 source SBOM，不推送、不加载模型，也不自动创建公开发行物。结果见 [公开验证记录](../verification/README.md)。

源码推送与正式发布分开：只有获得明确批准，才创建 tag/Release 或上传产物。CI、签名、校验和和独立模型效果需分别说明，不能以一次本地软件测试冒充已通过。
