# Public verification records

Record only reproducible commands, actual code/test results and known limitations. Use synthetic fixtures or separately licensed public inputs whose redistribution is permitted.

Do not publish household observations, camera/room mappings, capture times, device identifiers, machine paths, personal names, private hashes, model responses derived from household media, runtime PIDs or private artifact locations. Keep original household experiment records outside Git.
